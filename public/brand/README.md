# Assets oficiales de DBN Growth

- `dbn-growth-wordmark.png`: logo horizontal. Se usa en navegación y footer.
- `dbn-growth-icon.png`: isotipo. Se usa en favicon y visualizaciones del sistema.
- `dbn-growth-banner.png`: banner de referencia suministrado. No se usa como fondo obligatorio.
- `dbn-growth-emblem-glow.png`: variante luminosa suministrada para futuras composiciones.

La imagen social se encuentra en `app/opengraph-image.png`. Se generó a partir del banner oficial para mantener la identidad sobre un fondo oscuro.

No cambies la geometría, proporciones o colores de los logos. Para sustituir un archivo, conserva el mismo nombre o actualiza sus referencias en el código.
